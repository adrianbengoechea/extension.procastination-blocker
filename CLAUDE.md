## Project Overview

Procrastination Blocker — a Chromium extension (Manifest V3) that blocks distracting websites. Under active migration from vanilla JS to Preact + Vite.

## Development

### Build Commands
```bash
npm run dev      # Watch mode with live rebuild
npm run build    # Production build to dist/
npm run preview  # Preview built extension
```

### Loading the Extension
1. Run `npm run build`
2. Navigate to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the `dist/` folder
5. After code changes, rebuild or click the refresh icon on the extension card

### Tech Stack
- **UI**: Preact with TSX (no Tailwind — plain CSS in `src/assets/styles/global.css`)
- **Build**: Vite with `vite-plugin-web-extension` plugin
- **Manifest**: V3, generated from `src/manifest.json` with version synced from `package.json`

## Architecture

### Data Flow
```
options page (Preact) → chrome.storage.sync
  → background service worker listens for storage changes
  → rebuilds blocking rules
  → navigating to blocked domain redirects to blocked.html
```

### Key Files

**`src/manifest.json`** — Manifest V3 source. Permissions: `storage`, `activeTab`, `tabs`. The build plugin merges version from `package.json`.

**`src/background/index.ts`** — Service worker stub. Currently only logs install. Must be extended to:
- Listen to `chrome.storage.onChanged`
- Rebuild `declarativeNetRequest` dynamic rules when `blockedSites` changes

**`src/utils/messaging.ts`** — Message helpers. `sendMessage<T>()` for popup→background, `sendTabMessage<T>()` for background→content, `onMessage()` for listening.

**`src/hooks/useStorage.ts`** — Custom hook for reactive `chrome.storage.sync` reads. Returns `[value, set]`.

**`src/options/`** — Options page (Preact TSX). Manages blocked sites list. `useStorage('blockedSites', [])` pattern.

**`src/popup/`** — Extension popup (Preact TSX).

**`src/content/index.ts`** — Content script loaded on all URLs.

### Storage Schema
`chrome.storage.sync` stores `{ blockedSites: string[] }` — array of domain strings (no protocol, no `www.`).

### Missing / Incomplete
- Blocking via `declarativeNetRequest` is not yet implemented (permission missing, background is stub)
- `options.html` and `popup.html` exist but are generated by Vite from TSX entry points
- No tests configured
